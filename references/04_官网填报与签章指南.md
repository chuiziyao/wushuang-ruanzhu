# 官网填报与签章指南

面向操作者本人。系统为「中国版权保护中心 · 著作权登记系统」，入口 ccopyright.com.cn，账号与实名认证由申请人自己做，本技能不代办。

## 一、开工前的准备

| 项 | 要求 |
|---|---|
| 企业营业执照副本 | 扫描件或清晰照片，四角完整，300dpi，用于实名认证与上传 |
| 法定代表人信息 | 姓名、证件号；实名认证环节会核验 |
| 经办人（如非法人本人） | 授权委托书，按系统模板填写并盖章 |
| 统一社会信用代码 | 18 位，与营业执照逐字一致 |
| 银行或对公信息 | 部分认证路径会要求对公打款验证 |
| 材料 | 程序鉴别材料 PDF、文档鉴别材料 PDF、签章页 PDF |

官费为零。凡出现「官方加急费」「登记费」「插队费」的说法均不成立，收的是代理服务费，可自行判断是否需要。

## 二、注册与实名认证

1. 打开 ccopyright.com.cn，进入「著作权登记系统」，点「用户注册」。
2. 主体类型选**企业**，名称填营业执照全称，不得用简称。
3. 登录后进入「用户中心 → 实名认证」，按提示上传营业执照、填写法人信息，提交后等待审核（通常数个工作日，以系统提示为准）。
4. 认证通过前无法提交申请，但可以先在系统里起草表单。

**卡点**：认证被退回最常见的原因是执照照片反光、缺角、名称与工商登记差字。营业执照上的名称里带括号的，括号全半角都要一致。

## 三、六个页签怎么走

系统顶部固定六个步骤，逐页「下一步」，中途可保存退出。

```
① 选择办理身份 → ② 软件申请信息 → ③ 软件开发信息 → ④ 软件功能与特点 → ⑤ 确认信息 → ⑥ 填报完成
```

| 步骤 | 要做什么 | 注意 |
|---|---|---|
| ① 选择办理身份 | 选著作权人主体（企业/个人），关联已实名认证的主体 | 一个账号可管理多个主体，选错主体后面全错 |
| ② 软件申请信息 | 权利取得方式、软件全称、软件简称、版本号、权利范围 | 简称留空不要填「无」；全称不带版本号 |
| ③ 软件开发信息 | 软件分类、软件说明、开发方式、开发完成日期、发表状态、著作权人 | 开发完成日期不得早于主体成立日期 |
| ④ 软件功能与特点 | 六栏环境、编程语言、源程序量、开发目的、面向领域、主要功能、技术特点、鉴别材料上传 | 每栏有实时字数计数，超字存不进；主要功能 500 字起 |
| ⑤ 确认信息 | 全表逐字复核 | 这一步之后改动要退回重填，务必看两遍 |
| ⑥ 填报完成 | 生成《申请确认签章页》 | 打印、盖章、扫描、回传 |

填报顺序建议：先在本地把 `01_填报清单.md` 逐项粘完，再进系统。系统页面有超时，边想边填容易白填。

## 四、上传材料

- 只接受 **PDF**。程序鉴别材料、文档鉴别材料分两个上传位，一般交存各传一个文件；文件多时用「增加其他文档」。
- 出 PDF 用 `docx2pdf.py`（本机 Word 导出，不压行距、不缩放），也可自己在 Word 里另存，效果一致。
- 单个文件压到 **20MB 以内**，超限会静默失败。
- 文件名规范：`软件全称_源程序.pdf`、`软件全称_操作说明书.pdf`。
- 上传后**必须点开预览确认页数**，系统偶尔会截断页数。

## 五、签章页（最容易翻车的一步）

填报完成后系统生成《计算机软件著作权登记申请表》确认签章页，流程固定：

1. **在线打印**，不要复制内容到新文档重排。系统明确要求不得更改内容和打印比例。
2. A4 单面打印，页边距保持默认，不缩放、不加页眉页脚。
3. 企业在「申请人签章」处盖**公章鲜章**，不要用打印的电子章；个人申请则本人签字。
4. 多页签章页需**骑缝章**或逐页盖章，按系统提示。
5. 盖章后**扫描为 PDF**（300dpi，彩色），回传到系统的「签章页上传」位置。
6. **回传有时限**（通常要求在规定期限内完成，逾期视为未提交），提交当天就盖章回传最稳。

签章页无章、章不清楚、格式被改过、比例被缩放，都属于不予受理的常见情形。

## 六、提交之后

| 节点 | 说明 |
|---|---|
| 受理通知书 | 提交后数个工作日内出，可在用户中心查看 |
| 审查 | 自受理日起 60 日内完成审查（法定上限），实操常见 30–40 个工作日 |
| 补正通知 | 收到后 **30 日内**补正，逾期视为撤回。补正只改被指出的问题，别顺手改别的 |
| 登记证书 | 审查通过后发放电子证书（PDF，带登记专用章），用户中心下载 |
| 变更/补充 | 名称、著作权人变更走「登记事项变更」，版本大升级作为「修改」版本另案申请 |

## 七、提交前自查（照着打勾）

- [ ] 软件全称、版本号在申请表 / 源代码页眉 / 说明书页眉三处逐字一致
- [ ] 软件简称留空或填了真简称，没有填「无」
- [ ] 开发完成日期 ≥ 主体成立日期，且 ≤ 今天
- [ ] 已发表的填了首次发表日期与地点，且 ≥ 开发完成日期
- [ ] 主要功能 ≥ 500 字，模块名与前 30 页代码对得上
- [ ] 环境类五栏每栏 ≤ 50 字，编程语言其他栏 ≤ 120 字，技术特点补充 ≤ 100 字
- [ ] 源程序量与代码 Word 的有效行数同口径
- [ ] 源代码每页 ≥ 50 行、无空行、页码连续、共 N 页与实际一致
- [ ] PDF 已转、页数已数、单文件 ≤ 20MB
- [ ] 营业执照名称、信用代码与系统填的一致
- [ ] 签章页鲜章已盖、已扫描、已回传
