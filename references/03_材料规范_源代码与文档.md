# 材料规范：源代码与文档鉴别材料

> 封面、页眉、页脚的逐项规格见 `05_版式规范_封面页眉页脚.md`，本文只列与内容相关的要求。

## 一、程序鉴别材料（源代码）

### 1.1 硬性要求与工程实现

| 要求 | 官方口径 | 本技能的实现 |
|---|---|---|
| 页数 | 一般交存：前连续 30 页 + 后连续 30 页；总量不足 60 页交全部 | 总页数 ≤ 60 只出完整稿；> 60 额外出一份前 30 + 后 30 |
| 每页行数 | 不少于 50 行，末页可为程序结束页 | 每页恰好 50 行，末页不足 50 行属允许情形 |
| 空行 | 不应出现 | 全文去空行，全角空格与制表符统一处理 |
| 页眉 | 左：软件全称 + 版本号 | 宋体 9pt，左对齐，与申请表逐字一致，页眉下 0.75 磅实线 |
| 页码 | 右上角，连续 | 右对齐「第 X 页 共 N 页」，X 用 PAGE 域，N 为生成时算出的真实页数 |
| 页脚 | 不写 | 留空，不写公司名、日期、水印 |
| 封面 | 不需要 | 无封面，第 1 页即代码 |
| 排版 | 纵向、从左向右 | A4 纵向，左对齐，Consolas 9pt / 宋体 |
| 内容 | 优先核心业务代码，不交第三方库与生成物 | 按路径打分排序，`src/core/app/server` 优先，测试与配置靠后 |

### 1.2 为什么不会在 Word 里跑版

三件事同时锁死，缺一件就会散：

1. **固定行距**：14 磅精确行距，50 行 = 700 磅；A4 去掉上下页边距（2.0 + 1.8cm）后可用高度 734 磅。余量 34 磅，足够放页眉与页眉线。
2. **强制分页**：每页第一段设「段前分页」（`pageBreakBefore`），不依赖 Word 自动分页，行数不会跨页漂移。
3. **宽度预折行**：按显示宽度折行（中文记 2、半角记 1），单行上限 96 单位 ≈ 475 磅，小于可用宽度 493 磅（21 − 1.8 − 1.8cm）。中文注释不会撑破右边界。

改字号或行距时，用 `--line-pt`（默认 14）、`--font-size`（默认 9）、`--max-units`（默认 96）联动调整；生成器会先算 `行数 × 行距` 是否超过可用高度，超了直接报错退出，不会静默产出跑版文件。

### 1.3 两份文件的关系

```
源代码_完整.docx        1 … N 页（N 为真实总页数）
源代码_前30后30.docx    第 1–30 页 + 第 N−29 – N 页
```

第二份的页码有两种口径，用 `--number-mode` 切换：

| 模式 | 页码表现 | 适用 |
|---|---|---|
| `continue`（默认） | 1–60 连续，页眉写「共 60 页」 | 提交稿自成一体，审查员看到的就是一份完整的 60 页材料，最不容易被问 |
| `original` | 前 30 页 1–30，后 30 页沿用完整稿真实页码（如 549–578），页眉「共 N 页」 | 想让审查员能直接对上完整源代码的页码 |

两种都合规，**不要混用**：一份材料里出现两套编号才是不合规。

### 1.4 提交前必须做的三件事

1. **脱敏**：API 密钥、支付密钥、数据库口令、内网 IP、真实用户数据一律清除或替换为 `***`。生成器会按文件名关键词（secret / token / key / .env / password）自动排除并在统计 JSON 里点名，但**内容级密钥必须人工过一遍**。
2. **剔除第三方**：`node_modules`、`vendor`、`site-packages`、引擎生成目录（Library/Temp/obj/bin）、`*.min.js`、lockfile 全部剔除。生成器已内置排除，仍要抽查文件清单。
3. **核对源程序量**：把 `源程序统计.json` 里的「源程序量_有效行数」填进申请表，与代码 Word 同口径。

### 1.5 常见退回原因

| 现象 | 原因 | 处理 |
|---|---|---|
| 要求补正「源代码页数不足」 | 每页不足 50 行、或大量空行凑页 | 重跑生成器，`--lines-per-page 50` |
| 要求补正「前后页不连续」 | 手工删页导致断号 | 用第二份文件，别手剪 |
| 「软件名称与申请表不一致」 | 页眉写简称、漏版本号 | 重出，`--name` 用全称 |
| 被认为「非自主开发」 | 前 30 页全是配置、依赖、自动生成代码 | 调整代码排序，把核心业务模块放前面 |
| 材料含敏感信息 | 密钥、真实数据未脱敏 | 清除后重出 |

## 二、文档鉴别材料（操作说明书）

### 2.1 要求

| 项 | 要求 |
|---|---|
| 类型 | 用户手册 / 操作说明书 / 设计文档，任选一种。推荐操作说明书 |
| 页数 | 前 30 页 + 后 30 页（不足 60 页交全部） |
| 每页行数 | 不少于 30 行（整页界面截图页不受此限） |
| 页眉 | 同源代码：软件全称 + 版本号，宋体 9pt，右侧「第 X 页 共 N 页」 |
| 页脚 | 同源代码：留空 |
| 封面 | 独占第 1 页，不显示页眉页码；正文页码自 1 重新起算 |
| 页码 | 右上角，「共 N 页」按正文页数计（不含封面） |
| 截图 | 必须有，且是软件真实运行界面，与申请表功能描述、代码模块对得上 |

文档页数由 Word 排版决定，无法预先算出。**超 60 页时的正确做法**：整本导 PDF，再用 PDF 工具提取第 1–30 页与最后 30 页合并，页码保持原样。不要手工删 Word 段落。

### 2.2 推荐结构

```
封面           著作权人全称 / 软件全称 / 版本号 / 文档名称（不放日期、Logo、网址）
目录           Word 自动目录，含页码
一、软件概述    定位、适用对象、主要能力（对齐申请表「主要功能」的模块名）
二、运行环境    硬件、操作系统、支撑软件（对齐申请表对应五栏，措辞一致）
三、安装与启动  安装步骤、首次启动、参数配置
四、功能操作    每个模块一节：功能说明 → 操作步骤 → 界面截图 → 结果说明
五、数据与设置  存储位置、导入导出、权限、清除数据
六、常见问题    5–10 条，一问一答
```

功能章节必须与「软件的主要功能」一一对应：申请表写五个模块，说明书就五节，名字用同一套词。

### 2.3 截图：要不要放，放多少

**要放。** 官方没有把截图写成强制项，但审查员判断「这份文档写的是不是这个软件」，靠的就是界面截图。整本纯文字、一张图没有的手册，被要求补正的概率明显更高；反过来，图与文对得上，是最好用的自证材料。

数量与摆法：

| 项 | 建议 |
|---|---|
| 总量 | 30 页的手册放 8–15 张，平均每 2–3 页一张 |
| 每节 | 核心功能 1–2 张，辅助功能 0–1 张 |
| 尺寸 | 宽度铺满正文栏（约 15cm），同一套图同一分辨率，不拉伸变形 |
| 图注 | 图下居中，「图 4-1 事件记录界面」，编号与目录「图目录」一致 |
| 整页图 | 手机竖屏截图可整页放一张，该页不适用「不少于 30 行」 |

纪律：

- 用真实运行界面截图，**不用 AI 生成图、不用设计稿、不用宣传图**。
- 截图里的软件名称、版本号、界面元素与申请表一致。
- 关掉系统通知、微信弹窗、浏览器书签栏、IDE 控制台、任何 AI 工具水印。
- 涉及密钥、账号、真实用户数据的字段打码。
- 图片格式 PNG，不要用 JPG 二次压缩的糊图。

操作上不用手工插图：说明书 Markdown 里写 `![图 4-1 事件记录界面](img/shot1.png)`，图片就位后重新生成即可；缺图时 Word 里会留「【此处插入界面截图：…】」占位，并在同目录生成 `截图清单.md`，照着清单补拍。

## 三、转 PDF

一条命令出稿（走本机 Word/WPS 的 COM，不下载任何库，44 页约 4 秒）：

```bash
python scripts/docx2pdf.py --input 源代码_完整.docx --output 源代码_完整.pdf
python scripts/docx2pdf.py --input 操作说明书.docx --output 操作说明书.pdf
# 说明书超 60 页：截页 + 合并
python scripts/docx2pdf.py --input 操作说明书.docx --output 前30.pdf --pages 1-30
python scripts/docx2pdf.py --input 操作说明书.docx --output 后30.pdf --last 30
python scripts/docx2pdf.py --merge 提交稿.pdf 前30.pdf 后30.pdf
```

也可以不用命令，直接在 Word 里「文件 → 导出 → 创建 PDF」，两条路等价。注意事项：

1. 不要用「打印到 PDF」再勾缩印，缩放会把 50 行压成 45 行。
2. 转完打开 PDF 数三处：总页数、首页页码、末页页码。
3. 单文件控制在 20MB 以内；超了用 PDF 压缩（图像降采样到 150dpi 即可，文字层不要动）。
4. 营业执照、签章页扫描件 300dpi，四角完整，不裁边。
5. PDF 文件名用「软件全称+材料类型」，如 `示例事项记录软件_源程序.pdf`，与申请表名称一致。
